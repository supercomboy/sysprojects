# Resources

Chứa **non-visual resources**: string localization, images, icons, fonts.

Ví dụ dự kiến:
- `Strings.vi-VN.resx` (Phase 24)
- `Strings.en-US.resx` (Phase 24)
- `Icons.xaml` (ResourceDictionary chứa Geometry / DrawingImage)
- `Fonts.xaml`

Quy tắc:
- Không hardcode string UI trong XAML – dùng resource.
- Icon vector dạng `Geometry`, không dùng emoji production.
